# mrf-diagnostic-model

Диагностическая модель на марковском случайном поле (MRF) для восстановления скрытых причин по наблюдаемым симптомам.

## Задача

Есть наблюдаемые симптомы (O1–O5): падение прибыли, рост просроченной дебиторки, низкий темп новых контрактов и т.д. Нужно по ним восстановить **скрытые причины** (H1–H5), которые напрямую не видны.

## Что реализовано

- **Класс `MRF_Graph`** — марковское случайное поле с унарными и парными весами
- **EM-алгоритм** — обучение весов при скрытых переменных
- **Гиббс-семплирование** — генерация синтетических данных
- **Simulated annealing (имитация отжига)** — поиск MAP-конфигурации
- **Валидация** — сравнение с логистической регрессией + проверка на синтетике
- **Визуализация** — диагностическая карта через networkx

## Стек

- Python 3
- numpy, pandas, scikit-learn, networkx, matplotlib
- pickle (сохранение весов)
